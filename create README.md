## Deployment
This website is hosted on Netlify.

## Continuous Deployment
The GitHub repository is connected to Netlify.
Whenever changes are pushed to GitHub, Netlify automatically deploys the updated website.

## 404 Page Testing
Open a URL that does not exist on the website to test the custom 404 page.
